## 新しくなったこと

- **Bluetooth 接続（詳細設定）**: PC をテスト署名モード（Secure Boot をオフ）にした場合に限り、Magic Trackpad を Bluetooth でつないだまま、
  ポインター・スクロール・ピンチ・3・4 本指ジェスチャー・Force Touch と振動・ランチャーを使えるようになりました。
  インストーラーの「詳細設定」で選びます。PC の安全性を下げる設定変更が必要なので、先に [docs/BLUETOOTH.md](https://github.com/horiken1216/magitra/blob/main/docs/BLUETOOTH.md) を読んでください
- ロック中・ログオン前は、Bluetooth のトラックパッドも Windows 標準のマウスに自動で戻ります（ロック画面では 1 回クリックするとつながります）
- `mtpswitch.exe` で MAGITRA のドライバーに戻す引数を `magitra` にしました（`winusb` も使えます）

USB 接続だけで使う場合は、これまでと同じです。テスト署名モードは要りません。

## 導入

`mtpsetup.exe` をダウンロードして実行します（[導入と取り除き](https://github.com/horiken1216/magitra/blob/main/docs/INSTALL.md)）。
正式なコード署名がないため、SmartScreen の警告が出ます。「詳細情報」→「実行」で進めてください。
入れ直すと、以前の版は自動で置き換わります。

このファイルは GitHub Actions がこのリポジトリのタグからビルドしたものです。
