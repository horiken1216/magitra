## 新しくなったこと

- **Linux 版**: Linux でも、ポインター・スクロール（慣性つき）・ピンチ・2 本指のダブルタップ・3・4 本指ジェスチャー・Force Touch と振動・ランチャー・トレイと設定画面を使えるようになりました。
  USB でも Bluetooth でも、そのまま使えます（Linux ではドライバーの差し替えもテスト署名モードも要りません）。
  Lubuntu 26.04 と Magic Trackpad で、USB・Bluetooth の両方を確かめています。ほかのディストリビューション・デスクトップ環境は、ビルドと導入を確かめただけです。
  仕組み・導入・困ったときは [docs/LINUX.md](https://github.com/horiken1216/magitra/blob/main/docs/LINUX.md) を読んでください
- **LXQt 版**: キーの既定値を LXQt に合わせ（メニューとデスクトップの表示のキーは、LXQt のショートカットの設定から取ります）、設定画面が LXQt の設定センターに出る版です。
  Lubuntu はこちらを使ってください（[docs/LXQT.md](https://github.com/horiken1216/magitra/blob/main/docs/LXQT.md)）

Windows 版は、0.3.0 から動作の変更はありません。

## 導入

### Windows

`mtpsetup.exe` をダウンロードして実行します（[導入と取り除き](https://github.com/horiken1216/magitra/blob/main/docs/INSTALL.md)）。
正式なコード署名がないため、SmartScreen の警告が出ます。「詳細情報」→「実行」で進めてください。
入れ直すと、以前の版は自動で置き換わります。

ウイルス対策ソフトが、このファイルを「疑わしいファイル」として止めることがあります（Bitdefender の `Gen:Suspicious.Cloud` など）。
署名がなく利用実績の少ない exe で、中の PowerShell が証明書・ドライバー・サービスを変更するため、評判や振る舞いで疑われやすいのが理由で、
特定のマルウェアを見つけたという判定ではありません。止められると、ダウンロードしたファイルが警告の Web ページ（数 KB）に置き換わり、
「この PC では実行できません」と出ます。気になる場合はソースから自分でビルドしてください（[BUILD.md](https://github.com/horiken1216/magitra/blob/main/docs/BUILD.md)）。
例外に入れてダウンロードしたときは、下の SHA-256 と `Get-FileHash mtpsetup.exe` の結果が同じかを必ず確かめてください。

### Linux（Ubuntu 24.04・26.04 と、その派生の Lubuntu など）

使っている Ubuntu の版に合う `.deb` をダウンロードして入れます。Ubuntu の版が違う `.deb` は、依存するパッケージの名前が違うため入りません。

| 使っているもの | ファイル |
|---|---|
| Lubuntu 26.04（LXQt） | `magitra-lxqt_0.4.0_ubuntu26.04_amd64.deb` |
| Lubuntu 24.04（LXQt） | `magitra-lxqt_0.4.0_ubuntu24.04_amd64.deb` |
| Ubuntu 26.04（ほかのデスクトップ環境） | `magitra_0.4.0_ubuntu26.04_amd64.deb` |
| Ubuntu 24.04（ほかのデスクトップ環境） | `magitra_0.4.0_ubuntu24.04_amd64.deb` |

```sh
sudo apt install ./magitra-lxqt_0.4.0_ubuntu26.04_amd64.deb
```

入れると常駐サービス `magitrad` が起動し、ログインし直すとトレイに虎のアイコンが出ます。取り除くときは `sudo apt remove magitra-lxqt`（汎用版は `magitra`）です。
入れる前に、下の SHA-256 と `sha256sum` の結果が同じかを確かめてください。

このファイルは GitHub Actions がこのリポジトリのタグからビルドしたものです。
