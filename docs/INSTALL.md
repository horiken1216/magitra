# 導入と取り除き

## 必要なもの

- Windows 10 / 11（x64）
- Magic Trackpad と、**データ通信ができる** USB ケーブル（充電専用のケーブルでは動かない）
- 管理者権限（導入と取り除きのときだけ）

Bluetooth 接続には対応していない（[できないこと](#できないこと)）。

## 対応機種

| 機種 | PID | 状態 |
|---|---|---|
| Magic Trackpad（Lightning、2021 年の第 3 世代） | 0x0265 | **実機で確認済み** |
| Magic Trackpad 2（Lightning、2015 年） | 0x0265 | 第 3 世代と同じ PID・同じ扱い。実機では未確認 |
| Magic Trackpad（USB-C、2024 年の第 4 世代） | 0x0324 | **仮対応**（実機未確認）。受け付けるようにしてあるが、動く保証はない |

第 4 世代は、公開情報で第 3 世代と同じ作り（振動用の Actuator が MI_02・出力レポート 0x53 など）と報告されているため、
PID 0x0324 も受け付けるようにしてある。次の点は確かめていない。

- マルチタッチのレポートが MI_01 にあるか（WinUSB は MI_01 に当てる）
- マルチタッチへの切り替えが同じ `02 01` で、フレームの形式（ヘッダー 12 バイト＋指 9 バイト）・座標の範囲が同じか
- 振動レポートが同じ意味か

第 4 世代を試すときは、導入する前に、標準の HID のまま構成を調べると安全（Python 3 と `hidapi` が必要）。

```bat
python probe\enum_devices.py
python probe\caps.py
```

インターフェイスごとのコレクション・レポート ID・長さを、[調査記録](research/FINDINGS.md)の「USB 接続時」の表と比べる。

## インストーラーで導入する

`mtpsetup.exe` を実行する（作り方は [BUILD.md](BUILD.md)）。管理者権限の確認が出る。

| 選択肢 | 内容 |
|---|---|
| UIAccess 版を導入する（おすすめ） | 管理者権限のウィンドウ（タスクマネージャーなど）でも操作できる。その場限りの証明書を作って署名し、公開鍵だけをこの PC の「信頼されたルート」に登録する |
| 標準版を導入する | 証明書の信頼は不要。管理者権限のウィンドウでは操作できない。UIAccess 版が動かなくなったとき（管理ツールが証明書を取り除いた場合など）は、これを選んで入れ直す |
| 取り除く | WinUSB を外して標準のマウスに戻し、証明書・`C:\Program Files\MAGITRA`・「アプリ」の一覧の登録を消す（ユーザーの設定は残る） |

選べるオプション（どれも既定でオン）:

- **ロック中とログオン前は、標準のマウスとして使えるようにする**: サービス MagitraSwitch（システム権限・自動起動）を登録する。
  ログオンして使っている間だけ WinUSB、それ以外（ログオン画面・ロック中・ログオフ中）は Windows 標準の HID に切り替える。
  標準の HID でもポインター移動と左右のクリックは使える。切り替えには 2〜3 秒かかる
- **ログオンしたら常駐アプリを自動で起動する**: ログオン直後にサービスが常駐アプリを起動する（約 1 秒）
- **終わったら常駐アプリを起動する**

導入されるもの:

| 場所 | 内容 |
|---|---|
| `C:\Program Files\MAGITRA\` | 常駐アプリ `mtpagent.exe`、設定画面 `mtpsettings.exe`、ランチャー `mtplauncher.exe`、サービス `mtpswitchsvc.exe`、手動で切り替える道具 `mtpswitch.exe`、インストーラー `mtpsetup.exe` |
| ドライバーストア | WinUSB を当てる INF（`MtpUsb.inf`、Magic Trackpad の MI_01 だけが対象） |
| 証明書ストア | 導入ごとに作る署名用の証明書（`CN=MAGITRA Local Signing`）。署名したらすぐ秘密鍵を消すので、ほかのものには署名できない |
| `HKCU\Software\MAGITRA\Agent` | ユーザーごとの設定（設定画面で変えたときに作られる） |
| `C:\ProgramData\MAGITRA\` | サービスの記録 `switch.log`（サービスを入れたとき。管理者と SYSTEM だけが書ける） |

導入が途中で止まったとき:
- ファイルを置き換える前に止まった場合は、その導入で加えたドライバーと証明書を戻し、導入前の状態のままにする
- ファイルを置き換えた後で止まった場合は、以前と新しい証明書の両方を残す。もう一度導入し直すか、「取り除く」で元に戻す

### 証明書について

- 証明書は導入のたびに作り、MAGITRA のファイルに署名したら秘密鍵を消す。信頼されるのは、その導入で署名したファイルだけ
- タイムスタンプを付けられないので、証明書の期限は 20 年にしている
- WinUSB のカタログも同じ証明書で署名する（標準版では信頼の登録はしない。署名が未信頼でも導入できる）
- 証明書の信頼の登録はセキュリティ設定の変更にあたる。**組織が管理する PC では、規定で許されているかを先に確かめる**

### 導入したあと

- 影響するのは `USB\VID_05AC&PID_0265&MI_01`（と第 4 世代の `PID_0324&MI_01`）だけ。ほかのインターフェイス・Bluetooth 接続・ほかの機器は変えない
- **常駐アプリが動いている間だけ**、トラックパッドで操作できる（WinUSB を当てた MI_01 は Windows のマウスとして扱われないため）。
  常駐アプリを終了すると、USB 接続のトラックパッドは動かなくなる
- デバイスマネージャーの「ユニバーサル シリアル バス デバイス」に Magic Trackpad の WinUSB が出ていれば、ドライバーは入っている
- 使い方は [USAGE.md](USAGE.md)

## 取り除く

「設定」→「アプリ」の一覧の「MAGITRA」からアンインストールするか、`C:\Program Files\MAGITRA\mtpsetup.exe` で「取り除く」を選ぶ。
WinUSB が外れ、トラックパッドは Windows 標準のマウスに戻る。ユーザーの設定（`HKCU\Software\MAGITRA\Agent`）は残る。
WinUSB を外せなかったときは、そこで止まり、ファイル・証明書・「アプリ」の一覧の登録は残す（トラックパッドを使う手段をなくさないため）。再起動してから、もう一度「取り除く」を実行する。

## 困ったとき

| 症状 | 確かめること |
|---|---|
| トラックパッドが動かない | タスクトレイに虎のアイコンがあるか（なければ `C:\Program Files\MAGITRA\mtpagent.exe` を起動）。アイコンにマウスを重ねると状態が出る |
| 常駐アプリが「見つかりません」と言う | USB ケーブルがデータ通信用か。WinUSB が入っているか（`C:\Program Files\MAGITRA\mtpswitch.exe status`） |
| ロック画面で動かない | サービスを入れたか（インストーラーのオプション）。記録は `C:\ProgramData\MAGITRA\switch.log` |
| 管理者権限のウィンドウで操作できない | 標準版を入れている。UIAccess 版で入れ直す |
| UIAccess 版が起動しなくなった | 証明書が取り除かれた可能性がある。インストーラーでもう一度導入するか、標準版で入れ直す |
| すぐに標準のマウスに戻したい | 管理者権限で `C:\Program Files\MAGITRA\mtpswitch.exe hid`（戻すときは `winusb`） |

## できないこと

- **Bluetooth 接続**: Bluetooth では、Windows がトラックパッドを普通のマウスとしてしか見せず、指ごとのデータ（レポート 0x31）を
  途中で捨てる。取り出すにはカーネルのフィルタードライバーが必要で、テスト署名モードか、Microsoft の署名が要る。
  試作（`drivers/MtpBth`）はあるが実機では未検証（[research/BLUETOOTH-SPIKE.md](research/BLUETOOTH-SPIKE.md)）。
  Bluetooth でつないだ場合は、Windows 標準のマウスとして動く
- **Windows 標準のタッチパッドのジェスチャー・設定**: Precision Touchpad としては見せていないので、Windows の「タッチパッド」の設定は効かない。
  ジェスチャーは MAGITRA の設定画面で変える
- **ストアアプリをランチャーに登録する**: スタートメニューにショートカット（.lnk）がないアプリは選べない
