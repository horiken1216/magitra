# 使い方

導入は [INSTALL.md](INSTALL.md)。設定は `HKCU\Software\MAGITRA\Agent` にユーザーごとに保存される（名前・範囲・既定値は `agent/mtp_settings.h`）。

## タスクトレイ

常駐アプリ（`mtpagent.exe`）が動いていると、タスクトレイに虎のアイコンが出る。
トラックパッドを使っているときは濃い虎、使っていないとき（未接続・一時停止・ロック中）は薄い虎。
タスクバーの明るい表示・暗い表示に合わせて、黒と白を切り替える。
アイコンにマウスを重ねると状態が出て、クリックするとメニューが開く。

| メニュー | 内容 |
|---|---|
| 設定... | 設定画面を開く |
| 一時停止 | 入力を送るのを止める（押したままのボタンは離す） |
| ナチュラルスクロール | スクロールの向き（オンで Mac と同じ） |
| Force Touch | 1 本指で強く押し込んだときの動作のオン・オフ |
| 3・4本指ジェスチャー | 3・4 本指で払う操作のオン・オフ |
| ログオン時に起動 | ログオン時に常駐アプリを自動で起動する |
| 終了 | 常駐アプリを終了する（終了すると、USB 接続のトラックパッドは動かない） |

- USB ケーブルを抜いても終了しない。つなぎ直すと 2 秒以内に再接続する
- ロックするとトラックパッドを Windows に返し（ロック画面で標準のマウスとして使えるように）、解除すると 2〜3 秒でつなぎ直す

## 設定画面

左の分類を選んで、右の項目を変える。**変えた瞬間に保存され、動いている常駐アプリにすぐ反映される。**
スライダーは、つまみ以外を押すとその位置へ動く。右端の「既定」でそのスライダーだけを既定値に戻せる。

| 分類 | 変えられるもの |
|---|---|
| ポインター | ポインターの速さ・加速、スクロールの速さ、ナチュラルスクロール、慣性スクロールと滑る長さ、ピンチ、2 本指ダブルタップの割り当てと間隔 |
| クリック | Force Touch のオン・オフ、発動に必要な押し込みの強さ、強く押し込んだときの操作 |
| 振動 | Force Touch の振動の強さ・鋭さ・重さ（「試す」で鳴らせる。上限は安全とされる範囲に固定） |
| ジェスチャー | 3・4 本指ジェスチャーのオン・オフ、3・4 本指 × 上下左右の割り当て |
| ランチャー | 既定のブラウザーを出すか、並べるものの追加・並べ替え・削除・変更 |
| 全般 | 常駐アプリの状態と起動、ログオン時に起動、すべての設定を既定に戻す |

割り当てられる操作: なし、右隣・左隣の仮想デスクトップ、タスクビュー、デスクトップの表示、直前のアプリに切り替え、
中クリック、戻る、進む、再生・一時停止、検索、拡大率を元に戻す（Ctrl+0）、ランチャー

## 指の操作

### 1・2 本指

| 操作 | 動き |
|---|---|
| 1 本指で動かす | ポインター（速く動かすほど遠くへ動く加速付き） |
| 押し込む | 左クリック。押したまま動かすとドラッグ |
| 2 本指で押し込む | 右クリック |
| 2 本指で動かす | スクロール（既定はナチュラルスクロール） |
| 2 本指で払って離す | 慣性スクロール。勢いでしばらく続き、どこかに触れると止まる |
| 2 本指を広げる・つまむ | 拡大・縮小（Ctrl + ホイールとして送る。ブラウザーや Office などで使える） |
| 2 本指でダブルタップ（押し込まない） | 既定は「拡大率を元に戻す」（Ctrl+0。Word・Excel では別の操作になる） |

- スクロールやピンチの後は、指を全部離すまでポインターは動かない（離す途中の指の動きを拾わないため）
- 2 本指を広げたつもりでも、指の中心が先に大きく動いたときはスクロールになる

### Force Touch

- 1 本指で押し込むと、約 0.15 秒だけ様子を見てから左ボタンを送る。その間に強く押し込めば Force Touch になる
  （左クリックは送らず、重い振動と、割り当てた操作を送る。既定は中クリック）
- 様子を見ている間に指を約 2mm 動かすと、すぐにドラッグになる（押したままのドラッグで誤って発動しないため）
- 押してしばらくたってから強く押し込んでも Force Touch にはならない
- 普通のクリックの確定が最大 0.15 秒遅れる。気になる場合は Force Touch をオフにすると、押した瞬間に左ボタンを送る
- 押した・離したときの「カチッ」はトラックパッド本体の振動。Force Touch の振動は、押し込んだ直後に加わる重い「ブルッ」

### 3・4 本指

| ジェスチャー | 既定の操作 | 送るキー |
|---|---|---|
| 3 本指で左へ払う | 右隣の仮想デスクトップへ（Mac と同じ向き） | Ctrl+Win+→ |
| 3 本指で右へ払う | 左隣の仮想デスクトップへ | Ctrl+Win+← |
| 3 本指で上（奥）へ払う | タスクビュー | Win+Tab |
| 3 本指で下（手前）へ払う | デスクトップの表示 | Win+D |
| 4 本指で左右に払う | 直前のアプリに切り替え | Alt+Tab |
| 4 本指で上（奥）へ払う | ランチャーを開く | - |
| 4 本指で下（手前）へ払う | なし | - |

- 約 10mm 払うと 1 回だけ発動する。指を離すまで続けては発動しない
- 斜めすぎる動きは向きを決められないので発動しない
- 3 本以上で触れた後は、指をすべて離すまでポインターもスクロールも動かない

## ランチャー

4 本指で上へ払うと、ポインターのある画面の中央に一覧が開く（`mtplauncher.exe`）。

- クリックするか、文字を打って絞り込み、矢印キーと Enter で起動する。Esc・外側のクリック・ほかのウィンドウへの切り替えで閉じる
- 先頭には、そのユーザーの既定のブラウザー（https を開くアプリ）を出す。登録したものとは別で、設定でオフにできる
- 設定画面の「ランチャー」で、アプリやファイル（スタートメニューのフォルダーから選べる）・フォルダー・URL を登録する。
  名前・対象・引数はあとから変えられる。名前を変えていなければ、対象を変えると名前も合わせて変わる
- 起動はエクスプローラーに頼む（スタートメニューから起動したのと同じになる）
