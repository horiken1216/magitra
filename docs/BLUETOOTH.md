# Bluetooth 接続（詳細設定）

Magic Trackpad を **Bluetooth でつないだまま**、USB と同じ機能（ポインター・スクロール・ピンチ・3・4 本指ジェスチャー・Force Touch と振動・ランチャー）を使うための詳細設定。
自作のカーネルドライバー **MtpBth** を使うので、**PC をテスト署名モードで起動している場合だけ**使える。

> **普段使いには USB 接続をおすすめする。** Bluetooth のためには、PC の安全性を下げる設定変更（Secure Boot をオフ、テスト署名モード）を利用者自身が行う必要がある。
> 変更の意味が分からない場合や、組織が管理する PC では使わないこと。

## なぜテスト署名モードが要るのか

Bluetooth でつなぐと、Windows はトラックパッドを普通のマウスとしてしか扱わず、指ごとのデータは取り出せない。
取り出すには、Windows 標準の Bluetooth HID ドライバー（HidBth）の代わりに、トラックパッドと直接やりとりするカーネルドライバーが要る。

Windows が普通に読み込むカーネルドライバーには、Microsoft の署名（EV 証明書と Microsoft のアカウントが必要）が要る。MAGITRA にはそれがないため、
インストーラーがその場限りの証明書で署名したドライバーを、**テスト署名モード**の Windows に読み込ませる。

ハードウェアを足す方法（Bluetooth ドングルを別に用意するなど）は採っていない。調べた経緯は [research/FINDINGS.md](research/FINDINGS.md) と [research/DESIGN-NOTES.md](research/DESIGN-NOTES.md)。

## 引き換えになるもの

| 項目 | 内容 |
|---|---|
| Secure Boot をオフにする | 起動時にファームウェアが OS の起動部分を確かめる仕組み。オフにすると、起動前に入り込むマルウェア（ブートキット）を防げなくなる |
| テスト署名モード | Microsoft の署名がないドライバーも読み込まれるようになる。デスクトップの右下に「テスト モード」と常に表示される |
| BitLocker | Secure Boot を切り替えると、次の起動で回復キーを求められることがある。**先に回復キーを控えておく** |
| ゲーム | チート対策のあるゲームの中には、テスト署名モードでは起動しないものがある |
| 証明書の信頼 | 導入ごとに作る証明書（公開鍵のみ）を「信頼されたルート証明機関」と「信頼された発行元」に登録する。秘密鍵は署名後すぐに消す |
| カーネルドライバー | 不具合があるとブルースクリーンになりうる。MtpBth が当たるのは Magic Trackpad だけで、ほかの Bluetooth 機器には触らない |

メモリ整合性（HVCI）はオンのままで動いた（実機で確認）。

## 確かめた範囲

| 項目 | 状態 |
|---|---|
| Magic Trackpad（Lightning、第 3 世代、PID 0x0265） | **実機で確認済み**（Windows 11） |
| Magic Trackpad 2（PID 0x0265） | 同じ扱い。実機では未確認 |
| Magic Trackpad（USB-C、第 4 世代、PID 0x0324） | 受け付けるようにしてあるが、未確認 |
| ポインター・クリック・スクロール・ピンチ・3・4 本指ジェスチャー・Force Touch の振動 | 実機で確認済み。約 88 フレーム/秒 |
| ロック中・ログオン前に Windows 標準のマウスへ戻る | 実機で確認済み（切り替えは約 2 秒。下の「ロック画面では」） |
| 長く放置してトラックパッドが眠ったあとのつなぎ直し | 十分には確かめていない |

## 導入の手順

以下は利用者が自分で行う。MAGITRA のインストーラーは、Secure Boot・起動の設定・BitLocker には触らない。

### 1. BitLocker の回復キーを控える

管理者権限の PowerShell で:

```powershell
manage-bde -protectors -get C:
```

「数字パスワード」の 48 桁を控える。「デバイスの暗号化」の場合は https://account.microsoft.com/devices/recoverykey でも確かめられる。BitLocker が無効なら不要。

### 2. Secure Boot をオフにする

1. 設定 → システム → 回復 →「PC の起動をカスタマイズする」の「今すぐ再起動」
2. トラブルシューティング → 詳細オプション →「UEFI ファームウェアの設定」→ 再起動
3. UEFI の設定画面の Security（または Boot）にある **Secure Boot** を **Disabled** にして、保存して再起動する（項目の場所は PC のメーカーで異なる）
4. `msinfo32` の「セキュア ブートの状態」が「オフ」になっていればよい

### 3. テスト署名モードを有効にする

管理者権限の PowerShell で:

```powershell
bcdedit /set testsigning on
```

**再起動する。** デスクトップの右下に「テスト モード」と出れば有効。再起動するまでは有効にならない（インストーラーも Bluetooth を選ばせない）。

### 4. トラックパッドを Bluetooth でペアリングする

設定 → Bluetooth とデバイス →「デバイスの追加」で、普通のマウスとしてペアリングする。

### 5. インストーラーで「Bluetooth 接続でも使う」を選ぶ

`mtpsetup.exe` を実行し、版を選んだうえで、**詳細設定**の「Bluetooth 接続でも使う（テスト署名モードの PC のみ）」をオンにする。
ロック画面でも使えるよう、「ロック中とログオン前は、標準のマウスとして使えるようにする」もオンにしておく。

インストーラーが行うこと:

- ドライバー（`MtpBth.sys`）とそのカタログに、導入ごとに作る証明書で署名し、秘密鍵を消す
- その証明書を「信頼されたルート証明機関」と「信頼された発行元」に登録する
- ペアリング済みの Magic Trackpad に MtpBth を当てる（Windows 標準の HidBth と入れ替わる）

導入した後は、タスクトレイの常駐アプリが Bluetooth のトラックパッドを使う。USB と Bluetooth の両方がつながっているときは USB を使う。

## 使うときの違い

- **常駐アプリが動いている間だけ**、Bluetooth のトラックパッドで操作できる（USB と同じ）
- **ロック画面では**: ロックするとサービスが約 2 秒で Windows 標準の HidBth に戻す。このとき Bluetooth の接続が一度切れるので、
  **トラックパッドを 1 回クリックしてつなぎ直す**（このクリックは Windows に届かない）。ロック画面の最初の画面（時計）ではポインターが出ないので、
  キーを押してパスワードの画面に進めてからクリックすると分かりやすい。解除すると約 2 秒で MAGITRA に戻る
- 振動は Bluetooth でも USB と同じ設定で鳴る

## やめるとき

**順番が大事。** MtpBth を入れたままテスト署名モードをやめると、MtpBth が読み込まれず、Bluetooth のトラックパッドがマウスとしても動かなくなる。

1. MtpBth を外す。次のどちらか:
   - インストーラーで「Bluetooth 接続でも使う」をオフにして導入し直す（USB の MAGITRA は使い続ける場合）
   - インストーラーで「取り除く」（MAGITRA ごとやめる場合）

   外れたら、**トラックパッドを 1 回クリック**すると Windows 標準のマウスとしてつながり直す
2. テスト署名モードをやめる（管理者権限の PowerShell で `bcdedit /set testsigning off`、再起動）
3. Secure Boot をオンに戻す（導入の手順 2 の逆）

順番を間違えて Bluetooth のトラックパッドが動かなくなったときは、USB でつなぐか別のマウスを使って、インストーラーで MtpBth を外す。
それでも戻らなければ、Bluetooth の設定でトラックパッドを削除して、ペアリングし直す。

## 困ったとき

| 症状 | 確かめること |
|---|---|
| インストーラーで「Bluetooth 接続でも使う」が選べない | テスト署名モードで起動しているか（右下に「テスト モード」の表示。`bcdedit` の後に再起動したか） |
| 「ペアリング済みの Magic Trackpad が見つからない」と出た | Bluetooth でペアリングしてから、もう一度導入する |
| 常駐アプリが「見つかりません」と言う | デバイスマネージャーの「システム デバイス」に **Magic Trackpad (MAGITRA Bluetooth)** があるか。`C:\Program Files\MAGITRA\mtpswitch.exe status` |
| しばらく使わなかったら動かない | トラックパッドをクリックして起こす。数秒たっても動かなければ、トラックパッドの電源を入れ直す |
| ロック画面で動かない | 1 回クリックしてから数秒待つ。サービスを入れたか（インストーラーのオプション）。記録は `C:\ProgramData\MAGITRA\switch.log` |
| すぐに標準のマウスに戻したい | 管理者権限で `C:\Program Files\MAGITRA\mtpswitch.exe hid`（戻すときは `magitra`）。そのあと 1 回クリック |

開発者向けの手順（インストーラーを使わずに入れる `drivers\spike.ps1`、生のフレームを見る `mtpdump`）は [research/BLUETOOTH-SPIKE.md](research/BLUETOOTH-SPIKE.md)。
